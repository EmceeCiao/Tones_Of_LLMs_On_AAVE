# Likert Scale 

1. Answer Quality

    Which response did a better job addressing what the user asked for?

    - A did a much better job

    - A did a slightly better job

    - No meaningful difference

    - B did a slightly better job

    - B did a much better job 

2. Clarity

    Which response was easier to understand?

    - A was much clearer

    - A was slightly clearer

    - No meaningful difference

    - B was slightly clearer

    - B was much clearer

3. Warmth

    Which response felt more friendly and engaging?

    - A was much warmer

    - A was slightly warmer

    - No meaningful difference

    - B was slightly warmer

    - B was much warmer


4. Overall Preference

    Which response would you rather receive?

    - Strongly prefer A

    - Slightly prefer A

    - No preference

    - Slightly prefer B

    - Strongly prefer B 

    Briefly explain why you preferred Response A, preferred Response B, or had no preference (Required) 
 
5. Social Appropriateness Check

    Did either response feel condescending, stereotyping, or otherwise socially inappropriate?

    - Neither response

    - Response A

    - Response B

    - Both responses 

    Briefly describe what made the response(s) feel condescending, stereotypical, or otherwise socially inappropriate (Optional)
